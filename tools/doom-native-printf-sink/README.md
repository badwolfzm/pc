# Genuine Doom bounded printf output adapter (no host stdout)

Task #249. This new isolated freestanding source provides the single genuine pending `printf` import using the already merged `vsnprintf` runtime provider. A trusted Warden guest runtime must deliberately install a callback using `warden_printf_bind` before formatting can emit bytes. With no callback, `printf` returns -1 and writes nothing; there is no host stdout, `FILE`, host syscall or direct kernel console bypass.

One `printf` call allocates a fixed **4096-byte stack buffer**, rejects negative/unsupported format results and results too large to fit including the NUL terminator, and refuses callbacks that write fewer than all requested bytes. The sink is not a security capability: it must be implemented as an independently reviewed guest-to-Warden rights-checked transport. No callback implementation is supplied. Function pointer and context are process-local mutable globals; this prototype assumes one guest thread and is **not thread safe** or reentrant. The callback must not recurse to `printf`. The negative path can return after partial external writes if a callback misbehaves; it cannot roll those writes back.

The CI uses *genuine pinned* 79 original Doomgeneric translation units and five Warden adapters, combines 16 existing providers from the exact known candidate #238, and then real `ld -r` with this adapter. It must resolve **exactly one** pending symbol (`printf`), retain all protected `system`/host file/process imports, and introduce no new unresolved symbols. Freestanding provider itself should export exactly `printf` and `warden_printf_bind`, importing only `vsnprintf`. Host unit tests exercise fail-closed unbound state, callback transfer, short write, formatting error and oversize output.

**Not yet done:** trusted Warden console implementation/rights check, final static ELF, native Doom gameplay, bounded guest resident-memory proof under one vCPU/512 MiB, performance/FPS, Albion Online. Do not merge as a fully functional console service. Independent runtime/ABI/security owner review required. This code does not alter Warden kernel, ABI, graphics, WAD, native formatter, or any other agent's owned files.
