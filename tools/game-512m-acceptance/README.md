# Warden game 512 MiB evidence acceptance (initial validator)

Implements the **first, host-only evidence validator** for issue #138 and merged vision PR #134. This is a validator of supplied JSON, **not** a guest telemetry collector, actual pager, or verified 512 MiB game benchmark. It distinguishes `model_only` from `guest_verified` so an offline simulation cannot be presented as a real boot. Use `python3 tools/game-512m-acceptance/validate.py report.json` (exit 0 accepted, 1 rejected). Run unit tests: `python3 -m unittest discover -s tools/game-512m-acceptance -p 'test_*.py' -v`.

Required schema v1: exact 40-hex Warden commit and 64-hex executable digest; `guest.physical_ram_bytes` in `(0, 536870912]`; `guest.vcpus` exactly 1; `guest.graphics` (`software` or `integrated_gpu`); `guest.storage_authorized` true; and mutually exclusive byte buckets `kernel`, `personality`, `game_resident`, `framebuffers`, `page_tables`, `pager_cache_metadata`, `other` whose sum must not exceed assigned RAM. `guest_verified` also requires evidence source `native_warden_qemu`, two unique successful boots/clean exits, observed input/state progress and 300 strictly timestamped, 16-hex-digest frames for **each** boot.

The schema deliberately cannot authenticate self-reported telemetry, establish that memory buckets are truly disjoint, prove resource usage, inspect storage grants, detect fabricated hashes, validate the guest's actual -smp 1 CLI, or establish FPS/playability. Those require audited Warden telemetry collectors, signed provenance, run-specific game/asset/host hashes, measured resident/peak frame accounting, and independent live QEMU integration; do not mark `guest_verified` without those supporting artifacts. A JSON file passing these checks alone is not proof the game actually ran. The validator is a fail-closed *format/gate* for the future evidence pipeline. Negative tests cover 512 MiB+one-page, 2 vCPU, absent breakdown, authorization refusal, incomplete frame trace and duplicate boot IDs.

No kernel, ABI, renderer, or existing agent-owned files were edited. No actual game performance measurement is claimed.
